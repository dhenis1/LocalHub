# LocalFlix

LocalFlix is a personal, experimental Windows desktop application for organizing and playing a privately owned local media collection. It is developed for its author's own use on their computer.

This project is non-commercial. There is no intention to distribute, release, market, or promote the software. This public repository exists only as an identification page for the application, including its TMDB API access application. It contains documentation only; no application source code, executables, credentials, internal files, media files, or download links are published here.

## Intended use

The application is being developed to organize movies and television series, retrieve descriptive metadata, and associate entries with local files selected by the user. Planned metadata searches prioritize Brazilian Portuguese, with English as a fallback. TMDB integration is being prepared and requires approved API access; this page does not imply that access has already been granted.

LocalFlix does not provide, host, distribute, or download movies or television episodes. Local media is supplied by its user.

## TMDB attribution

Movie and television metadata and artwork are intended to be provided by [The Movie Database (TMDB)](https://www.themoviedb.org/) through its API, subject to the applicable terms.

This product uses the TMDB API but is not endorsed or certified by TMDB.
